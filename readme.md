# Foxgirl Tail Calculator

## Description

A mildly cursed web contraption that crunches numbers, spiritual essence, and old folklore to spit out the hidden stats of foxgirls. Enter a few details — age, height, tail count,
tail type — and watch as it reverse-engineers tail volume, mass, foxfire hue, and spirit power using questionable geometry and half-baked mysticism. For entertainment, heresy, and
questionable late-night curiosity.

## Features

- **Tail Analysis**: Generates over a dozen stats: tail size, mass, spirit power, foxfire color, and more.
- **Tail Customization**: Pick your fluff — Fluffy, Bushy, or Sleek — each messing with density and final numbers.
- **Archetype Presets**: Skip the guesswork — one-click profiles from baby Kits to near-divine Celestials.
- **Animated Feedback**: Tail fluff aura pulses and shifts as you play god.
- **Dark UI Magic**: Glowing gradients, drifting particles, and quietly humming numbers.
- **Works Everywhere**: Desktop, phone, ancient shrine terminal — if it runs a modern browser, it works.
- **For Nerds**: Pop-up modal explaining the unholy reasoning behind the numbers.

## Usage

1. Type in the foxgirl’s height in centimeters (50–250)
2. Add her age (from fresh spirit to ancient crypt keeper, 1–10,000+ years)
3. Choose tail count (1–9)
4. Select tail type (Fluffy, Bushy, Sleek)
5. Stare in awe (or mild regret) at the generated stats
6. Click archetype presets to summon ready-made builds
7. Read the help modal if you’re brave enough

## Installation

None needed. Open [https://foxgirl.decaded.dev](https://foxgirl.decaded.dev) in your browser, or drag `index.html` into the void (your browser tab).
